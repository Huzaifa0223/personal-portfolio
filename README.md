# Muhammad Huzaifa - Personal Portfolio

A sleek, responsive, and modern one-page personal portfolio website designed for full-stack software engineers and developers. Built with clean semantic HTML5, modern CSS3, and vanilla JavaScript.

![Portfolio Preview](https://img.shields.io/badge/Status-Live-success?style=for-the-badge)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

---

## 🚀 Features

- **Theme Toggle**: Seamless Dark and Light mode switching, persisted across visits with `localStorage`.
- **Hero Section**:
  - Live availability badge (`Available for new projects & opportunities`).
  - Dynamic typewriter effect cycling through core engineering specialties.
  - Interactive code preview card with floating stat badges.
- **Categorized Skills**: Clean breakdown of Frontend, Backend & APIs, Databases & Cloud, and Architecture & Tools.
- **Project Showcase**: Showcase cards featuring visual banners, technology chips, descriptions, and direct links to live demos and GitHub repositories.
- **Career & Education Timeline**: Sleek chronological milestones.
- **Interactive Contact Form**: Complete with form validation and simulated toast alerts.
- **Fully Responsive**: Optimized for ultra-wide screens, laptops, tablets, and smartphones with a custom mobile drawer menu.

---

## 🛠️ Built With

- **HTML5**: Semantic tags, accessible landmarks, and meta tags.
- **CSS3**: Custom CSS variables, Flexbox, CSS Grid, glassmorphism blur effects, and smooth animations.
- **Vanilla JavaScript**: Lightweight, zero-dependency DOM manipulation, IntersectionObserver for active scroll tracking, and animated number counters.
- **Typography & Icons**: [Outfit](https://fonts.google.com/specimen/Outfit), [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans), and [Font Awesome 6](https://fontawesome.com/).

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Huzaifa0223/personal-portfolio.git
cd personal-portfolio
```

### 2. View locally
Simply double-click `index.html` to open it in your default browser, or serve it using Python:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000`.
